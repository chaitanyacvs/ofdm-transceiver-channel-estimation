# OFDM Simulation Results

This directory contains the simulation outputs generated by the MATLAB-based OFDM transceiver project.

## Results

### 1. Channel Estimation
Shows the pilot-based least-squares (LS) channel estimates and interpolated channel response.

### 2. Channel Frequency Response
Visualizes the channel frequency response across the OFDM subcarriers.

### 3. OFDM Equalizer BER Comparison
Compares the bit error rate (BER) of Zero-Forcing (ZF), MMSE, and perfect-channel-knowledge reference equalization across the simulated SNR range.

## Simulation Configuration

- Modulation: QPSK
- FFT size: 64
- Cyclic prefix: 16 samples
- Channel: Multipath with AWGN
- Channel estimation: Pilot-based LS with linear interpolation
- Equalization: ZF and MMSE

See the main [project report](../OFDM_Project_Report.pdf) for methodology and implementation details.
